AI-Anton / Temberok

Личный помощник владельца для работы с разрешёнными данными Google. Приложение не предоставляет публичную регистрацию.

Возможности

  • Чтение событий и занятости Google Calendar, создание согласованных встреч.
  • Чтение и ведение задач Google Tasks по указанию владельца.
  • Поиск и чтение разрешённых писем Gmail, файлов Google Drive, документов, таблиц и контактов.
  • Получение только выбранных владельцем фотографий через Google Photos Picker.

Каждое подключение требует согласия Google. Данные используются для исполнения запросов владельца. Результат может обрабатываться подключённой AI-моделью и поступать владельцу через Telegram.

Поддержка: tember2k@gmail.com.
